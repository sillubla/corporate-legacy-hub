# Corporate Legacy Hub

Prototipo funcional desarrollado a partir del diseño de interfaz en **Figma**, estructurado y conectado mediante **Google Antigravity** y respaldado por **Supabase** como backend y base de datos.

## Stack Tecnológico

* **Diseño UI/UX:** Figma / Figma Make
* **Desarrollo e Integración Asistida:** Google Antigravity
* **Backend y Base de Datos:** Supabase (PostgreSQL & Auth)
* **Frontend:** HTML / CSS / JavaScript (React / Tailwind)

## Estructura del Proyecto

* `/src`: Código fuente de los componentes, vistas y lógica de conexión con Supabase.
* `package.json`: Dependencias y scripts de ejecución del proyecto.
